# Repositorio Principal con Múltiples Proyectos

Este repositorio contiene múltiples laboratorios, cada uno ubicado en una rama diferente.

## Estructura de Ramas

- **`Laboratorio1`**: Laboratorio con Lodash.
- **`Laboratorio2`**: Laboratorio con Web Components en parejas con [@GoldenDarkness21](https://github.com/GoldenDarkness21).
- **`Laboratorio3`**: Es un misterio. (No existe porque fue omitido, lol)
- **`Laboratorio4`**: Consumir una API REST con Web Components (Consumí la de Valorant).
- **`Laboratorio5`**: Uso de Flux, API REST y Web Components (Consumí la de Valorant again).
- **`Laboratorio6`**: Ecomerce con una API REST con Web Components (Consumí la FakeStoreApi).
- **`Laboratorio7`**: Gestor Personal de Tareas con Firebase.

## Cómo Iniciar un Proyecto

Para trabajar con un proyecto específico, sigue estos pasos:

1.  **Clona este repositorio principal (si aún no lo has hecho):**

    ```bash
    git clone https://github.com/SmallCakekoo/AlgorithmsLabs
    cd AlgorithmsLabs
    ```

2.  **Cambia a la rama del proyecto deseado:**

    ```bash
    git checkout <nombre_de_la_rama>
    ```

    Por ejemplo, para ver en el proyecto de la rama `Laboratorio7`:

    ```bash
    git checkout Laboratorio7
    cd Lab7
    ```

3.  **Instala las dependencias del proyecto:**

    ```bash
    npm install
    ```

4.  **Inicia el proyecto:**

    ```bash
    npm start
    ```

5.  **Cuando necesites cambiar a otro proyecto, cambia a la rama del otro proyecto:**

    ```bash
    git checkout <nombre_de_otra_rama>
    ```

    Luego repite los pasos 3 y 4.

## Notas Adicionales

- Asegúrate de tener Node.js y npm instalados en tu sistema.
- Cada rama contiene un proyecto independiente con su propio archivo `package.json` y dependencias.
